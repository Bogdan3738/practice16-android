# Практическая работа 16 — Пользователи

Android-приложение на **Java + XML** по шести предоставленным методическим материалам.

## Этап 1: практики 16.1–16.3
- Модель `User` и общий список пользователей.
- `ListView`, собственный `BaseAdapter`, повторное использование строк.
- Просмотр имени, статуса и возраста пользователя.
- Отдельная разметка `layout-land` с двумя панелями.
- Индикаторы: зелёный — онлайн, красный — офлайн, жёлтый — отошёл.

Исходники редактируются в Android Studio, установленной в облачной среде.

## Открытие
1. Клонировать репозиторий и открыть корневую папку в Android Studio.
2. Использовать JDK 17, Android SDK Platform 35 и Build Tools 34.0.0.
3. Выполнить Gradle Sync, выбрать представление **Android**.
4. Запустить конфигурацию `app` на устройстве Android 6.0 или новее.

Сборка из терминала: `./gradlew assembleDebug` (Windows: `gradlew.bat assembleDebug`).

Данные пока хранятся в памяти процесса, как предусмотрено методичкой.
